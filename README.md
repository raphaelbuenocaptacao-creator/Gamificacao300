# 🏆 Arena XP — Ranking & Performance

Aplicativo de ranking e gamificação da campanha BMW X1 2012.

## Base de dados

- Período inicial: 01/07/2026
- Base processada: até 09/08/2026
- Registros considerados no painel: contratos ATIVOS
- VGV ativo processado: R$ 14.805.551,91
- Vendas/casais ativos processados: 109

## Regras implementadas

- Liner: R$ 1.000 VGV = 1.200 XP
- Closer: R$ 1.000 VGV = 1.000 XP
- Presença: 50.000 XP/dia
- Pontualidade: 50.000 XP/dia
- Falta não gera XP de presença
- Atraso não gera XP de pontualidade
- Promotor: regras de bônus ainda pendentes no regulamento

## Controle de disciplina

A aba **Presença** permite lançar manualmente, por profissional e por data:

- Presente / Falta
- Pontual / Atrasado

Os lançamentos são salvos no navegador via localStorage nesta primeira versão.

## GitHub Pages

O aplicativo está em `index.html` e a base processada em `data.js`. Basta publicar o repositório como GitHub Pages para abrir como aplicativo web.
