🧮 Como o XP é somado

O aplicativo nunca recebe um “XP TOTAL” digitado. Ele calcula: XP Produção + XP Disciplina + XP Bônus = XP TOTAL. Se você corrigir presença, o sistema substitui o lançamento daquele dia em vez de duplicá-lo.

Histórico administrativo

📋 Motor de XP

Produção
Liner = 1.200 XP por R$1.000 de VGV
Closer = 1.000 XP por R$1.000 de VGV
Promotor/Captação = 1.400 XP por R$1.000 de VGV.

Disciplina
Presença = 50.000 XP/dia
Pontualidade = 50.000 XP/dia
Falta = 0 XP de presença
Atraso = 0 XP de pontualidade.

Bônus
TOP, ticket, eficiência e outros bônus entram pelo lançamento administrativo até que a base detalhada permita cálculo automático seguro. Assim evitamos pontuar ou duplicar algo que não esteja comprovado na base.
